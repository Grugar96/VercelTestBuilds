# Mulki Surf Brothers — brand assets

For reels, stories and anything outside the website. The website itself loads these fonts from Google Fonts through next/font.

```
brand/fonts/Oswald/   Oswald (variable + static weights). Use SemiBold 600 for poster headlines, Medium 500 for labels.
brand/fonts/Caveat/   Caveat (variable + static). SemiBold 600 for handwritten accents.
brand/fonts/Roboto/   Roboto (variable + static, incl. italics). Regular 400 / Medium 500 for captions and body text.
brand/logo/surfbrothers-logo-original.png        original 4168 px, transparent
brand/logo/surfbrothers-logo-trimmed-2000.png    empty margin removed, transparent
brand/logo/surfbrothers-logo-endcard-1080.png    trimmed, 1080 px wide, for reel end cards
```

Oswald, Caveat and Roboto are under the SIL Open Font License (see each folder's OFL.txt), so they can be shared and used commercially.
The lettering inside the logo is part of the logo artwork; only these three fonts are used anywhere else.

Full look & feel: see the "Brand look & feel" section of the project context doc, the Website Brand Guide v1.1, and `app/globals.css`.
